# NovaEdu 銀河英語探險（B2C 家長自學・序號販售商業版）

## 🚀 快速上線部署步驟
1. **合併圖音資產**：
   - 將步驟 2 & 3 生成的全部 **1,080 張 `.webp`** 解壓合併至本資料夾下的 `images/`（含 `0–100` 數字卡與 `num_000_zero.webp`）。
   - 將步驟 4 本機生成的全部 **1,477 個 `.mp3`** 放入本資料夾下的 `audio/`。
   - 執行 `python verify_assets.py`，確認圖檔與音檔顯示「缺漏：0」。
2. **設定雲端序號後端（免伺服器月租費）**：
   - 建立空白 Google 試算表 → 點選「擴充功能 → Apps Script」→ 貼入 `backend/Code.gs` 並修改 `ADMIN_PASSCODE`。
   - 部署為「網頁應用程式（任何人皆可存取）」後，將網址貼入 `data/nova-config.js` 的 `NOVA_GAS_URL`。
   - *(若暫不部署雲端，留空 `NOVA_GAS_URL` 亦可直接以本機示範模式體驗登入、3 台裝置限制與 4 大自學測驗。)*
3. **發卡與販售**：
   - 點擊首頁右下角「🔒 總部序號管理後台」，可批次產生單冊／單年級／全星系序號卡，並一鍵匯出印刷用 CSV。
